# AI 视频识别信号平台六人分工与任务进度说明

## 1. 文档用途
本说明用于把当前项目整体拆分为 6 个相对独立但互相关联的任务模块，便于在课程设计、项目汇报、组内分工说明或中期检查时，清晰展示：

- 项目总体由哪 6 个部分组成
- 每个人负责哪一部分
- 每一部分目前做到什么程度
- 每一部分使用了哪些框架、库和关键术语
- 后续还剩哪些工作可以继续推进

说明：

- 当前文档使用“成员 1 ~ 成员 6”作为占位符，后续可直接替换为真实姓名
- 文档中的进度判断，基于当前代码、配置、测试与运行链路的实际状态整理

## 2. 项目总体定位
本项目的核心目标不是做一个单纯的目标检测 Demo，而是做一套**面向安防场景的视频识别信号平台**。其总体链路可以概括为：

`视频源 -> 视觉检测 -> 目标跟踪 -> 规则判定 -> 告警事件 -> 信号输出 -> 前端展示 -> 管理与运维`

当前聚焦的业务场景主要有两个：

1. 园区围栏场景
2. 仓库与码头场景

对应的核心业务事件包括：

1. 翻越围栏
2. 人员滞留
3. 码头滞留
4. 仓库滞留
