# 同事电脑复刻部署说明

## 1. 适用目标
这份说明用于把当前项目完整复刻到另一台 Windows 电脑，并保证同事在没有接入真实摄像头的情况下，也能先用包内演示视频把系统跑起来。

默认交付策略：

- 后端与前端可直接启动
- 默认视觉模型使用 `models/yolo26s.pt`
- 默认演示视频使用相对路径，不依赖原电脑盘符
- 不包含你的私有 `.env` 密钥

## 2. 对方电脑前置条件

- Windows 10 或 Windows 11 64 位
- 已安装 Python `3.10.x` 或 `3.11.x`
- 安装 Python 时勾选 `Add Python to PATH`
- 首次安装依赖需要联网

可选：

- 如果对方电脑有 NVIDIA 显卡，希望获得更好的推理速度，可额外安装匹配的 GPU 版 `torch/torchvision`

## 3. 交付包里建议保留的内容

- `backend/`
- `frontend/`
- `config/`
- `scripts/`
- `models/`
- `data/acceptance_demo/` 中用于演示的样例视频
- `requirements.txt`

- `start_delivery.bat`

- `start_backend_dev.bat`

- `.venv/`

- 各类 `*.log`
- `data/runtime/ai_platform.db`
- `data/runs/`

- `data/uploads/`、`data/outputs/` 这类运行时产物
- 你本机真实 `.env`

## 4. 推荐部署步骤

### 4.1 解压

把压缩包解压到任意目录，例如：

```powershell
D:\AI_Video_Platform_Delivery
```

### 4.2 初始化环境

在项目根目录执行：

```powershell
.\setup_env.bat
```

脚本会自动：

- 创建 `.venv`
- 升级 `pip/setuptools/wheel`
- 安装 `requirements.txt`

### 4.3 可选：准备 `.env`

如果只是本地演示，不需要云端 Agent，可以直接使用交付包内默认 `.env`。

如果需要启用云端 Agent：

```powershell
copy .env.example .env
```

然后填入自己的：

- `API_KEY`
- `BASE_URL`
- `MODEL_NAME`

默认视觉模型建议保持：

```env
YOLO_WEIGHTS_PATH="models/yolo26s.pt"
```

### 4.4 启动

推荐先用交付模式：

```powershell
.\start_delivery.bat
```

启动后访问：

- 前端首页：`http://127.0.0.1:5500/index.html`
- 后端健康检查：`http://127.0.0.1:8000/health`
- 详情页：`http://127.0.0.1:5500/module.html?scene=campus_fence`

## 5. 默认演示模式说明

交付包建议把 `config/rules.yaml` 中三个摄像头的 `stream` 都改成包内相对路径演示视频，例如：

- `cam_fence -> data/acceptance_demo/demo_cam_fence_00969b0139d7baca21a2ba3d12012b0a.mp4`
- `cam_dock -> data/acceptance_demo/demo_cam_dock_00969b0139d7baca21a2ba3d12012b0a.mp4`
- `cam_warehouse -> data/acceptance_demo/demo_cam_warehouse_00969b0139d7baca21a2ba3d12012b0a.mp4`

这样对方电脑不接真实相机也能直接看到：

- 人员滞留
- 翻越围栏
- 码头/仓库区域滞留

## 6. 如果要切回真实摄像头

有两种方式：

### 6.1 直接改 `config/rules.yaml`

把对应摄像头的 `stream` 改回：

```yaml
stream: camera://0
```

或：

```yaml
stream: camera://1
```

### 6.2 用本地视频/采集链路调试

```powershell
.\start_webcam_demo.bat --camera-id cam_fence --source camera://0
```

或：

```powershell
.\.venv\Scripts\python.exe scripts\webcam_pipeline.py --camera-id cam_fence --source data\acceptance_demo\demo_cam_fence_00969b0139d7baca21a2ba3d12012b0a.mp4
```

## 8. 验证是否复刻成功

满足下面几项即可认为复刻成功：

- `http://127.0.0.1:8000/health` 返回 `status=ok`
- 首页能打开
- 详情页能看到视频流与框线
- 事件列表能出现 `人员滞留`、`翻越围栏`
- 管理员登录可用

## 9. 常见问题

### 9.1 `yolo26s.pt` 无法加载

先确认环境里实际安装的是：

- `ultralytics >= 8.4.41`

可执行：

```powershell
.\.venv\Scripts\python.exe -c "import ultralytics; print(ultralytics.__version__)"
```

### 9.2 端口 8000 或 5500 被占用

先关闭旧进程，再重新执行：

```powershell
.\start_delivery.bat
```

### 9.3 前端打开了但看不到新样式或新逻辑

浏览器执行一次强制刷新：

- `Ctrl + F5`

### 9.4 想启用 GPU

可以额外安装与你显卡匹配的 `torch` 与 `torchvision`，例如你们当前项目环境是：

- `torch 2.7.1+cu118`
- `torchvision 0.22.1+cu118`

如果只是答辩演示或功能复刻，CPU 也能跑，只是速度更慢。
