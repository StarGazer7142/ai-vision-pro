# 组员电脑部署与运行说明

## 1. 适用范围
- 项目名称：AI 视频识别信号平台
- 适用系统：Windows 10/11（64 位）
- 适用场景：组员拿到压缩包后，在新电脑完成环境安装并启动项目

## 2. 前置条件
- 已安装 Python `3.10.x` 或 `3.11.x`（安装时勾选 `Add Python to PATH`）
- 电脑可联网（默认在线安装依赖）
- 若使用摄像头或本地视频调试，确保设备/文件可访问

## 3. 解压后快速启动（推荐）
在项目根目录按顺序执行：

```powershell
.\setup_env.bat
.\start_delivery.bat
```

启动成功后访问：
- 前端首页：`http://127.0.0.1:5500/index.html`
- 后端健康检查：`http://127.0.0.1:8000/health`
- 场景页面：`http://127.0.0.1:5500/module.html?scene=campus_fence`
- 调试页面：`http://127.0.0.1:5500/debug.html`

## 4. 开发模式启动（可热更新）
```powershell
.\start_all_dev.bat
```

说明：
- 启动后会打开多个窗口（后端、前端、摄像头 demo）
- 若只想单独启动服务，可用：
  - `start_backend_dev.bat`
  - `start_frontend.bat`
  - `start_webcam_demo.bat`

## 5. 调试账号
- 用户名：`debug`
- 密码：`123456`

可通过环境变量覆盖：
- `DEBUG_USERNAME`
- `DEBUG_PASSWORD`
- `DEBUG_TOKEN_HOURS`

## 6. 常用命令
运行单元测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend\tests -p "test_*.py" -v
```

本地视频全链路联调：

```powershell
.\.venv\Scripts\python.exe scripts\webcam_pipeline.py --camera-id cam_fence --source data\uploads\videos\cam_fence\your_video.mp4 --no-view
```

## 7. 离线安装（可选）
如果项目根目录存在 `vendor\wheels`，`setup_env.bat` 会自动使用离线轮子安装依赖；否则走在线安装。

## 8. 常见问题
- 提示 `Python not found`：
  - 重新安装 Python 3.10/3.11，并勾选加入 PATH
- `setup_env.bat` 安装依赖失败：
  - 检查网络
  - 或让打包同学提供 `vendor\wheels` 离线依赖目录
- 端口冲突（8000/5500）：
  - 关闭占用端口的程序后重试

## 9. 打包说明（给交付同学）
在原始项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package_release.ps1
```

生成位置：
- `dist\AI_Video_Platform_Delivery_时间戳\`（打包目录）
- `dist\AI_Video_Platform_Delivery_时间戳.zip`（分发压缩包）
